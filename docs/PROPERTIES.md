# Engine properties

Generated by `tools/gen_properties_doc.py` from the engine's own reflection (`mods/propdump`). Property names and types are what `Entity:get_property/set_property`, `Quest`/`Info` `get_property/set_property` and `Info:*_command_property` accept; values use the engine's text format (enums as value names such as `gEGuild_Pir`, numbers and booleans as text, strings as-is). Use `list_properties` in the game to see the same list for any object.

## Entity property sets

Use the engine class name as `set`: `entity:get_property("gCNPC_PS", "Guild")`. A set is only available on entities that have it (`nil` otherwise); a set with no properties of its own is omitted.
